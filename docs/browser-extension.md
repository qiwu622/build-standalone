# 常用浏览器接入（0.3.0）

本连接器先让你在原来的 Chrome／Edge 里完成 Google 正常登录，再连接指定项目。不会改浏览器的自动化标识或尝试绕过 Google 验证。若 Google 仍要求验证，由用户按官方流程处理。

## 一次安装

Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启开发者模式，点击“加载解压缩的扩展”，选择本安装目录的 `extensions/build-browser-bridge`。不要选酒馆适配扩展，也不要选整个仓库目录。建议固定“Build 本机连接器”到工具栏。

扩展使用浏览器官方 `debugger` 权限操作你选中的 Build 标签页，因此浏览器会显示调试横幅。这个权限本身较强，请只安装你信任的本项目源码。代码限定到手动连接的 AI Studio Build 项目；不申请 cookies、全站 host 或远程调试端口。连接令牌只在内存，Google Cookie 不传给服务。

## 每次连接

1. 在常用浏览器正常登录，打开专用于此服务的 Build 项目。当前网页选择器要求英文界面，聊天框提示应为 `Make changes, add new features, ask for anything`。先处理页面上的订阅、验证或项目初始化提示；不要让服务绕过这些步骤。
2. 在管理页生成配对码。新配对码会替换旧配对码，5 分钟后失效。
3. 切回 Build 项目标签页，再打开扩展，填入管理页显示的本机服务地址（不带 `/v1`）和配对码，连接当前标签页。
4. 连接成功自动加入账号池，不需要再点“完成导入”。管理页显示“扩展在线”。此操作不发生成请求。
5. 需要添加其他账号时重新生成配对码；可使用另一个浏览器个人资料或正确账号索引下的专用项目。每次调用都核对邮箱、账号索引和项目；相同邮箱重新配对替换旧连接并保留冷却。

不要在连接器里填写管理员密钥/API Key。不要把配对码发送给他人。使用完可在扩展或管理页断开，原来的 Google 登录不退出。服务重启、扩展重载或浏览器关闭后重新配对即可。

## 调用条件与排查

- 浏览器和标签页需持续打开。断连不再显示为可用账号，当前请求会明确失败。
- 选中的项目用于自动新建聊天、切换模型/思考档位、上传和清理请求文件；不要选择含有重要未保存内容的项目。
- 开发者工具可能抢占该标签页的调试连接。关闭开发者工具后重新配对。
- 页面切换到登录页或其他项目后，扩展停止执行后续命令；请正常处理登录或恢复专用项目再连接。
- 配对时看到“输入框未就绪”：核对项目是否完成初始化、是否英文界面、是否已正常登录，并等页面加载完。
- 本版本机连接器仅允许 HTTP 回环地址，不提供远端公网扩展控制。Linux 桌面可运行，无桌面服务器暂不属于此模式的已验证范围。

## 验证范围

自动化测试覆盖真实本机 HTTP 传输配合模拟 Chrome API、配对鉴权/过期/重放、跨标签页隔离、Google 请求元数据过滤、超时撤销、文件原文传输和账号索引。它们不等于真实 Google 生成成功。

浏览器实现依据：[Chrome debugger API](https://developer.chrome.com/docs/extensions/reference/api/debugger)、[扩展 Service Worker 生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)。最低 Chrome 118，活动 debugger 会话用于维持扩展处理长请求；意外断连仍按失败处理。
