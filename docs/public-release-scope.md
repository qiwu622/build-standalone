# 0.7.0 公开发布范围

这是普通浏览器连接器版本，**不是公益站生产目录的副本，也不是低内存纯协议版本**。

## 包含

- 本机 OpenAI 兼容接口、管理页、账号调度、错误日志、安装/启动/更新脚本。
- 用户自行登录的 Chrome / Edge 专用 Build 标签页连接器与断线恢复。
- 等待期间的 SSE 保活；默认排队和生成不设内部总时限，取消、断连和上游错误仍生效。
- 酒馆预设分流：预设留在输入框，背景、世界书、历史放聊天附件。
- 可选函数工具协议；没有有效工具时不注入工具提示，工具由调用客户端执行。
- 中文 `-抗截断` 变体：要求模型把完整答案保存到请求专属文档，读取并校验后返回。

## 明确不包含

- Google WAA / BotGuard 签名计算、逆向虚拟机、字节码、反汇编或浏览器指纹实现。
- 纯协议低内存账号运行环境、共享 VM / isolate / heap、实验快照及其二进制。
- 公益站后台、计费库、用户数据库、服务器配置、真实账号、Cookie、密钥或生产日志。
- 第三方 proof API 的接入凭据或默认调用地址。

文档读取只解析已登录专用标签页本次生成的文件清单，校验项目、任务、随机文件名和 SHA-256。它不计算登录签名、不导出 Cookie，也不把普通浏览器包装成“每号 4 MB”。连接器需要持续打开浏览器。

## 抗截断使用

普通模型示例：`gemini-3.8-flash-low-抗截断`、`gemini-4-argon-抗截断`。

酒馆模型示例：`build-st/gemini-3.8-flash-low-抗截断`、`build-st/gemini-4-argon-high-抗截断`。

中文后缀放在思考档位后面；无档位时固定 high。每个基础模型和档位都提供普通/抗截断形式，合计 32 个含酒馆前缀的列表项。普通模型保持聊天正文输出。

抗截断仍然只发起一次生成，不自动续写，不突破 Google 的上下文/输出限制或内容限制。它减少聊天界面显示/复制造成的截断风险，不能保证模型一定写完所需内容。

该模式先完成文件写入，再返回文件正文；`stream: true` 等待期间发送心跳，正文完成后返回，**不是边生成边出字**。响应头 `x-build-output: document`、`x-build-streaming: buffered` 标明模式。

每次请求使用随机 `__bridge_reply_<24位随机值>.txt`。只读取最新已完成快照中的同名文件，拒绝其他项目/任务、缺失文件、错误摘要及超过 8 MiB 的文件，不将“已写好文件”的聊天提示冒充正文。请求后清理本项目保留命名空间中的输出文件；保留自己的其他项目文件。请勿手动使用这个保留文件名前缀。

升级服务后也需在扩展管理页重新加载 **0.7.0** 连接器并刷新专用 Build 页；旧连接器不支持文档命令，会在生成前拒绝抗截断请求。普通浏览器的网页结构可能变化，解析失败会明确报错，不会静默返回旧文件。

## 验证范围

本版本进行离线单元测试、模拟连接器测试、本机 HTTP/SSE 测试和发布内容检查。测试仅使用合成账号、模拟 Google 响应和临时本机服务。

本次发布 **Google 实际调用为 0**，未把模拟验收称为真实 Google 成功。普通连接器版新增加的文档输出尚需在使用者自己的 Google 会话中验收；此前其他服务端版本的验证不能代替此项。
