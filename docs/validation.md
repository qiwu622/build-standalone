# 验证范围

版本：0.3.0。日期：2026-10-29（Asia/Shanghai）。

0.3.0 增加常用浏览器扩展接入：真实本机 HTTP 配合模拟 Chrome API 已验证配对、账号隔离、Google 元数据过滤、超时撤销和 Unicode 文件原文传输。尚未在用户实际 Chrome／Edge 中加载扩展或通过 Google 生成；不以模拟测试代替真实验收。以下 0.2.0 的安装与酒馆结果仅作为历史基线。

| 项目 | 结果 | 范围 |
|---|---|---|
| 自动化回归 | 49/49 通过 | 原 42 项加 7 项扩展连接测试；本地 HTTP、模拟 Chrome API，无 Google 调用 |
| Windows 安装 | 通过 | 独立目录、依赖安装、配置及随机凭据初始化；PowerShell 5.1 与中文路径 |
| 0.1.0 → 0.2.0 升级 | 通过 | 新升级脚本包含扩展目录，保留配置、凭据和测试数据；回归通过 |
| 酒馆实际前后端 | 通过 | SillyTavern 1.13.2，隔离 dataRoot，真实浏览器和 Custom 后端，末端为本地断言执行器 |
| 预设/历史/世界书分流 | 通过 | 外部测试预设、合成背景、中途插入的预设；重建后的正文、角色和顺序一致 |
| 长历史分流 | 通过 | 约 19.5 万字符合成背景进文件，composer 约 1.1 万字符；不证明 Google 实际读取能力 |
| 错误处理 | 通过 | 来源无法核对、超预算、媒体/工具等不支持的输入在 Google 调用前拒绝 |
| 管理页 | 本地验证 | 桌面和手机宽度布局已检查；不是手机实机验收 |
| Google 实际登录/读取/生成 | 待验收 | 未把旧项目或假执行器的成功算作本版本实际生成通过 |
| 手机直接运行整套服务 | 未适配 | 当前目标为 Windows 与 Linux；手机可作为浏览器客户端，实机仍待验收 |

42 项自动化测试覆盖 API/admin 鉴权、Origin、非法输入、队列与取消、超时、实例控制、日志脱敏、账号隔离、额度冷却、思考档位核对、文件 Unicode 分片与校验、清理失败处理，以及酒馆专用封装与分流。

酒馆集成测试修复了两处差异：发送前复制消息数组，必须按内容核对；表格扩展会插入背景消息，需保持原消息完整及有序后才能接纳。另覆盖 51000 次重复提示词准备，避免来源标记登记耗尽。

私人测试预设、聊天、账号、原始日志和本机验收截图不公开。仓库测试只使用合成内容和 example.invalid 地址。请在自己的环境按 [真实验收步骤](live-acceptance.md) 验证，Google 网页行为和私有字段可能变化。
