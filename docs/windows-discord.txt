**🚀 Build Standalone 零基础部署教程｜1/4：安装项目**

**适用范围：Windows 10 / 11 电脑。**
本教程把 Build 项目装在你自己的电脑上，再接入同一台电脑上的酒馆。

**开始前准备好：**
- Chrome 或 Edge 浏览器。
- 一个已经能正常使用 Google AI Studio Build、且有目标模型权限的 Google 账号。
- 已经能打开的酒馆。还没装酒馆，先看官方 Windows 教程：https://docs.sillytavern.app/installation/windows/
- 这台电脑需要能访问 GitHub、Google AI Studio、nodejs.org 和 npm。

**① 打开 PowerShell**
按住键盘左下角的 **Win 键**，再按 **R**。
在弹出的小窗口输入 `powershell`，按回车。
会出现一个蓝色或黑色窗口，这是正常的，不用管理员权限。

**② 复制下面第一行，粘贴进窗口，按回车**
```powershell
Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/qiwu622/build-standalone/main/scripts/bootstrap.ps1 -OutFile "$env:TEMP\build-setup.ps1"
```

等它执行完，再复制下面第二行，粘贴并按回车：
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\build-setup.ps1"
```

**③ 等安装完成**
它会自己下载项目、准备运行环境并启动。你不用手动下载项目压缩包，也不用提前装 Node.js。
窗口里不断出现文字是正常的，安装期间先别关闭。

成功后会打开 **“Build 独立服务”管理页**，桌面也会出现 **“Build Standalone”快捷方式**。

> 管理页地址通常是 `http://127.0.0.1:8787`，也可能是别的数字。**以安装完成后实际打开的地址为准，不要照抄别人的端口。**
> 后面的操作都在同一台电脑完成。这里的 `127.0.0.1` 不能直接拿到另一台电脑或手机上用。

**🔑 Build Standalone 零基础部署教程｜2/4：连接 Google 账号**

**④ 找到管理密钥**
再次按 **Win + R**，把下面整行粘贴进去，按回车：
```text
notepad "%LOCALAPPDATA%\BuildStandalone\data\credentials.json"
```
记事本会打开一个文件，里面有两个名字：
- **adminKey**：用来登录 Build 管理页。
- **apiKey**：稍后填到酒馆里。

复制 `adminKey` 后面引号里的整段内容，填到管理页的 **“管理密钥”**，点 **“连接”**。
**只复制引号中间的内容，不带引号、逗号，也不复制 adminKey 这几个字。**
记事本先留着，后面还要用 `apiKey`。这两个密钥不要发给别人。

**⑤ 安装浏览器连接器，只需装一次**
用你平时登录 Google 的 Chrome 或 Edge：
- Chrome：在浏览器最上面的地址栏输入 `chrome://extensions`，按回车。
- Edge：在地址栏输入 `edge://extensions`，按回车。

打开 **“开发者模式”**，点击 **“加载已解压的扩展程序”**（Edge 可能叫“加载解压缩的扩展”）。
在弹出窗口上方的地址栏，粘贴下面路径并按回车：
```text
%LOCALAPPDATA%\BuildStandalone\extensions\build-browser-bridge
```
然后点 **“选择文件夹”**。不要选外面的 BuildStandalone 文件夹。

**⑥ 登录 Google 并自动接入**
回到 **同一个 Chrome / Edge** 里的 Build 管理页，刷新网页，重新填写 `adminKey`。
如果管理页原来开在其他浏览器，把它的完整地址复制到这个浏览器打开。

点击 **“登录并自动接入”**，在 Google 页面选择账号，完成登录和必要的验证。
项目会自动创建或复用专用 Build 项目，然后登记账号。**首次创建可能使用一次 Google 模型额度。**

回到管理页，账号显示 **“扩展在线”** 才算接好了。只看到 Google 已登录，还不算完成。

> **浏览器和自动打开的 Build 项目标签页要一直留着。** 可以最小化，别关闭，也别点调试提示条里的“取消”。调用时不要手动编辑那个项目。

**🍺 Build Standalone 零基础部署教程｜3/4：打开酒馆并填连接**

**⑦ 在装了连接器的同一个浏览器打开酒馆**
现在只装前面的 **一个浏览器扩展** 即可，里面已经包含酒馆预设分流。
不需要再到酒馆安装第二个扩展，也不需要油猴。

本机 `http://127.0.0.1` 或 `http://localhost` 地址自动启用。
如果用局域网 IP 或其他域名打开酒馆：点浏览器工具栏里的 Build 连接器，再点 **“在当前酒馆站点启用”**，允许访问这个站点。

按 **Ctrl + F5** 刷新酒馆，在扩展设置找到 **“Build 独立版 · 酒馆分流”**。
确认显示 **0.5.0（浏览器连接器内置）**，分流已默认开启，不需要另点开关。

> 以前装过 Build 酒馆扩展的，先在酒馆“管理扩展”里禁用旧版，再刷新。不要卸载浏览器里的 Build 连接器。

**⑧ 填酒馆 API 连接**
点击酒馆顶部的 **插头图标 / API 连接**，按下面选择：
- API 类型：**聊天补全 / Chat Completion**。
- 来源：**自定义 / Custom（兼容 OpenAI）**。
- API 地址：复制 Build 管理页 **“接口接入”** 里显示的 **Base URL**。
- API 密钥：填记事本文件里的 **apiKey**，不是 adminKey。

API 地址长得像这样，**这只是例子，端口用你自己的**：
```text
http://127.0.0.1:8787/v1
```
管理页复制出来已经有 `/v1`，不要再加一次，也不要自己加 `/chat/completions`。

模型名称填写：
```text
build-st/gemini-4-argon-high
```
然后点 **“连接 / Connect”**。如果找不到模型下拉列表，直接在自定义模型名称框粘贴上面的完整名字。

**“自定义请求正文”和“排除正文参数”保持空白。**
预设照常在酒馆里选择，不用导出，不用上传预设文件，也不用自己加标签。

**✅ Build Standalone 零基础部署教程｜4/4：开始聊天、下次启动和常见问题**

**⑨ 发一句话验证**
在酒馆新开一段对话，发送：
```text
这是连接测试，请只回复：你好。
```
这会真实调用 Google，并使用对应模型额度。

**先等，不要连续点发送。** 本项目目前是生成完整答案后一次显示，不会边生成边冒字；本机短回复实测约 1～2 分钟，具体时间会变化。
能看到正常回复，就完成了。

> `build-st/` 模型请用正常发送聊天来测试。酒馆的 **“测试连接 / Test Connection”** 不会读取预设，不适合验证这个模式。

**以后每次怎么打开？**
1. 双击桌面的 **Build Standalone**。
2. 用装好连接器的 Chrome / Edge 打开管理页，填写 `adminKey`。
3. 如果账号没在线，点一次 **“登录并自动接入”**。
4. 等显示“扩展在线”，再打开酒馆聊天。
5. 使用期间保持电脑、服务、浏览器和 Build 标签页运行。电脑睡眠或关机后不能继续调用。

**想换思考强度？只改模型名字最后一段：**
```text
build-st/gemini-4-argon-low
build-st/gemini-4-argon-medium
build-st/gemini-4-argon-high
```
分别是低、中、高。不会因为换名字就增加 Google 额度。

**出问题先看这里：**
- **管理页鉴权失败**：用 `adminKey`；酒馆用 `apiKey`。检查有没有多复制空格或引号。
- **没检测到连接器 / 账号离线**：确认连接器装在当前浏览器，刷新管理页，再点自动接入。
- **下载失败**：检查电脑能否访问 GitHub、nodejs.org 和 npm，再重跑安装脚本；本项目安装不需要 Git。
- **找不到 manifest.json**：加载浏览器扩展时选择安装目录里的 `extensions/build-browser-bridge` 文件夹。
- **分流未启用 / 仍显示旧版**：确认酒馆和 Build 在同一个装了连接器的浏览器；其他酒馆地址需在弹窗授权，旧酒馆扩展禁用后 Ctrl + F5。
- **管理页打不开**：先双击桌面快捷方式，使用它显示的实际地址。

**怎么更新？**
先等聊天结束，再重做第 1 条里的两行安装命令。它会更新项目，保留账号、密钥和配置。
也可直接双击安装目录里的 `update.cmd` 更新。新版只更新一个浏览器扩展即可。
浏览器连接器在 Chrome / Edge 扩展管理页点重新加载，再回管理页自动接入。
