Google 账号

每个账号使用独立浏览器资料。有桌面环境时，点击添加并在服务主机弹出的独立浏览器中完成 Google 官方登录。打开一个仅供本服务使用的 Build 项目，再完成导入。首次创建项目可能使用 Google 额度。

无桌面 Linux 服务器：先停止服务，通过已鉴权的 SSH X11 转发运行 npm run login，浏览器显示在管理员电脑上，资料保存在服务器；完成后启动 headless 服务。操作步骤见安装包 docs/linux.md。

独立登录窗口已打开。只保留一个专用项目标签页；请在 10 分钟内完成。
